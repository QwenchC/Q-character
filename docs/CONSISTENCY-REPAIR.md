# 多视图一致性检查与局部重绘

Windows 0.8.0 / Android 0.5.0 共用检查与重绘流程。沿用现有 Qwen-Image 2.1、BiRefNet 和 Pixal3D 权重，无需下载新模型或配置额外图片服务。

## 检查视图

1. 按 [多视图说明](MULTIVIEW.md)准备正面、背面和至少一个侧面，先完成各张抠图。
2. 点击“检查多视图一致性”。应用并列显示各方向，并为每个侧背方向建立“发型与发色、服装与层次、配饰与数量”三项核对记录。
3. 自动色差辅助会在透明前景内按人物高度取样：上部 0–34%，躯干 36–82%；分别比较主要色块并显示差异值。大于 18 / 100 提示重点对照。它是颜色取样工具，**没有语义分割，也没有自动识别服装结构、发型、配饰或遮挡**；面部肤色、光照和朝向变化也会导致色差，数值低不代表结构一致。
4. 人工对照图片，检查发色与发型体积、衣服颜色／层次／接缝、配饰数量／位置／形状。分别选择“已核对，一致”“有差异，需修正”或“该方向不可见／合理差异”。最后一项需要填写说明，例如背面看不到胸前徽章；背面不应机械复制正面图案。
5. 建立检查记录后，待核对、需修正和过期记录会阻止多视图建模。每次替换视图、修改蒙版或完成重绘，检查会按图片版本自动判为过期，须重新检查并确认。旧作品尚未开始检查时保留原有建模行为。

色差计算在当前设备执行，不上传图片；检查不会自动修改任何图片。对照图使用保存时的具体素材编号，旧记录不会随新图静默变成已确认。

## 涂选局部重绘

1. 在视图卡片或检查条目点击“局部重绘／涂选局部重绘”。只能重绘已抠图版本。
2. 画笔涂选需要修正的区域，红色表示将重绘。可擦除选区、调整笔刷大小和边缘硬度、撤销重做、缩放平移；Android 支持触屏涂选与双指缩放。初始选区为空，未涂选不能提交。
3. 在“局部修正要求”明确要改的颜色或部件，例如“围裙背带改为与正面相同的橄榄绿色，不添加徽章”。“查看其它方向参考图”可对照正面、侧面和背面。修正要求限制 2000 字。
4. 开始重绘后，Qwen 以当前方向为第一张目标参考，其余已抠图方向作为辅助，保留相机方向、姿势与比例。使用目标图的 VAE 编码作为起点，在选区加入噪声、以 0.7 去噪强度编辑，再自动抠图。
5. 应用在当前设备把结果合成回原图：选区为零的 RGBA 像素直接保留，软选区按预乘 alpha 混合。生成结果、选择蒙版、前景蒙版、修正要求和新抠图版本保留；完成时只有仍指向原目标的槽位才会自动换为新版本。
6. 检查重绘轮廓，必要时继续“查看／修正”恢复头发和配饰。重新运行一致性检查、确认各项后，再生成 Pixal3D 模型与贴图。

改变轮廓时要把原轮廓及希望延伸的周围区域一起涂选；选择范围太小可能出现接缝。局部重绘仍可能改变错误的细节或没有充分遵循要求，不会自动保证一致性。原图和旧版本保留，可以从槽位选择器切回。

## 同步和任务恢复

更新两端后使用原有 [作品同步](SYNC.md)：检查结果、遮挡说明、选区、修正要求、旧图与新图都随作品传输。在一端修正后同步，另一端会看到旧检查已过期，重新核对后可接着建模。

检查记录作为一个字段合并；两端离线同时核对时可能产生冲突副本，保留双方内容供选择。编辑说明或涂选时会暂缓自动刷新，Windows 同步服务会保护正在编辑的作品。生成期间不允许同步。

Android 已提交任务可按原 `prompt_id` 继续接收，恢复不会重复提交；中间下载图不视作重绘完成，只有保存最终抠图后才完成。手机仍需保持应用前台接收，或稍后重新打开找回任务。

[本次实测与边界](consistency-validation/README.md)包括 Windows／Android 真实 Qwen 局部重绘、选区外像素检查、核对记录同步及修正后建模。

## 0.11.0 / Android 0.8.0：修补边缘与颜色

自动抠图仍使用服务端稳定合成图确定前景；正式候选 RGB 保持为原始解码结果，手机或电脑只融合一次。客户端针对分离选区分别取未涂选、不透明的周边像素作参照，在相近材质内小幅校正颜色偏移；仅对原本平坦、低对比且沿选区过渡方向的边缘减弱痕迹。透明前景边缘、强对比配饰、复杂纹理及缺少可靠周边参照时采用保守处理，选区外 RGBA 逐像素保留。

此方法减少色差和圆形接缝，不能保证消除所有生成痕迹，也不能恢复图中没有的纹理。尽量沿材质边界涂选，避免把要保留的纽扣、发丝或配饰一并涂入。新版视觉节点可结合历史提示“可能为修补痕迹”，需要安装新节点并重启 ComfyUI；新报告、历史图和选区两端同步。[对照指标及限制](repair-blend-validation/REPORT.md)。
