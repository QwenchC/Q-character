# 手动修正抠图 · 0.3.0

## 使用

1. 生成或导入角色图片，点击“自动抠图”。已有抠图版本也能继续修正。
2. 在透明轮廓预览下点击“手动修正”。默认显示原图，红色覆盖表示将删除的区域。
3. 选择“恢复前景”，涂回被误删的衣服、头发、配饰；选择“擦除背景”，涂掉残留背景和阴影。
4. 调整笔刷大小（1–200 个原图像素）和边缘硬度。检查发梢时可使用较小、较软的笔刷。
5. 切换“透明结果”“黑白蒙版”“原图对照”检查轮廓。原图对照为只读视图，其他视图可直接涂画。
6. 点击“保存修正”。应用新增一张蒙版和一张透明抠图，并自动选中该抠图；确认后点击“生成 3D”。

滚轮在鼠标位置缩放；“移动画布”、空格拖动或鼠标中键拖动可平移。也提供缩放按钮、“适应窗口”和 100% 显示。笔刷圆圈随缩放变化，实际修改范围以原图像素为准。

每次拖动算一笔。Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Ctrl+S 保存。撤销历史最多保留 30 个状态，按图像尺寸限制在约 64MiB 的历史快照预算内；关闭编辑器后不保留笔画历史。点击取消、关闭修正或按 Esc 时，若有未保存修改，会在编辑器内询问是否放弃。编辑中的内容尚未写入磁盘，退出整个应用前请先保存。

## 原图与版本

恢复画笔从本次抠图对应的原始图片恢复颜色，不使用已经透明的抠图作为颜色来源。因此能找回自动抠图误删的浅色衣服、发梢和配饰。它只修正透明度，不补画原图中不存在的内容；如果导入的原图本身已透明或缺失内容，无法恢复那些内容。

每次保存使用独立文件名，记录原图、父抠图和新蒙版之间的关系。原图和旧版自动抠图不被覆盖；可以在缩略图列表切回旧版本，也能重新打开手修版本继续修改。保存失败时保持编辑器与笔画，错误显示在编辑器底部。

已有半透明原图的边缘不会因反复保存而重复乘透明度。手修蒙版表示最终不透明度，受原图透明度限制；软笔刷保留灰度边缘。预览和保存对极低透明度使用同一阈值。应用会拒绝空白、没有有效前景、尺寸错误、非灰度或含透明通道的外部蒙版请求。

手修在本机运行，不需要连接 ComfyUI，也不产生新的 AI 图片生成任务。点击“生成 3D”时，仍须连接 ComfyUI。3D 输入直接使用所选修正版本，按透明度裁切、居中和合成白底，不再重新自动抠图。

## 实际验证

2026-10-15，在 Windows / RTX 5090 32GB 上：

- 26 项自动测试、类型检查、生产构建通过。覆盖连续笔画、最细笔刷、软边缘、撤销重做分叉与历史上限、非法蒙版、半透明原图保留、串行保存和版本持久化。
- Electron 实际鼠标操作：恢复测试中误删的白色衣袖；快速拖动连续涂画；滚轮缩放、移动后擦除残留背景；撤销与键盘重做；保存后重新加载并再次打开编辑器。
- 对导出的 PNG 读取像素：衣袖透明度恢复到 255，残留背景降到 0；恢复位置的 RGB 与原图一致；旧抠图 SHA256 不变。取消和非法保存不会增加素材版本。
- 修正版本自动选中，实际提交混元 3D 标准流程并完成生成；导出 GLB、STL 和三视图。
- 导出的 GLB 经 Blender 5.1.1 实际导入，模型高度约为 0.08m，另存为 `.blend`。

记录和截图位于 `docs/mask-validation/`，桌面与 GPU 链路见 `report.json`，Blender 见 `blender-validation.json`。测试使用独立端口 8199 和项目内 `.runtime/mask-desktop`，与正式作品库分开。
