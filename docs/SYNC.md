# 电脑与手机作品同步

Windows 0.5.0 与 Android 0.2.0 可双向同步作品，在另一台设备继续修正蒙版、上色和配制黏土。Windows 提供同步服务；两端都保留本地作品，生成仍连接各自配置的 ComfyUI。

## 同一 Wi-Fi 下配对

1. 更新两端应用。在电脑点击右上角“作品同步”，保留默认端口 **8790**，点击“开启 HTTPS 同步服务”。若 Windows 防火墙询问，请允许应用通过当前可信的专用网络。
2. 在手机“作品同步”填写电脑显示的可访问局域网地址，例如 `https://192.168.1.10:8790`。不要填写 `127.0.0.1`；它在手机上指向手机自身。
3. 点击“检查同步证书”，逐段核对 SHA256 指纹与电脑显示的一致，点击授权并完成 Android 原生确认。证书授权仅对该协议、主机、端口及完整证书有效，不会关闭系统 HTTPS 校验。
4. 在电脑生成配对码，在手机填写并配对。8 位配对码有效 2 分钟，只能成功使用一次；失败过多时需重新生成。
5. 在手机点击“双向同步全部作品”或“只同步当前作品”。电脑会自动刷新收到的作品。请保持电脑应用运行，并让手机应用处于前台。

电脑可在设备列表“撤销访问”；撤销会终止该设备的连接。本机作品保留，手机再次同步需要重新配对。手机“断开配对”保留本机作品。证书更新、电脑地址变化时需要重新检查指纹并授权新地址。

## 接着编辑

同步包含作品名称、描述、风格、目标高度、原图、设计图、自动与手动画笔蒙版、透明图、3D 输入图、原始与彩色模型，以及素材之间的版本与参考关系。黏土目标色、色块命名、基础黏土和试配量随作品保存；当前参考图、模型版本与工作页也可恢复。

未保存的画笔或配色请先保存。电脑正在生成、编辑蒙版或有未保存配色的作品会暂停接收；手机同步期间也暂停生成和素材操作。稍后重试即可。同步不会自动恢复执行中的远端生成任务：任务记录会标为需找回，应在原生成端按任务编号接收结果。

手机可开启“应用在前台时每 30 秒自动同步”。应用处于前台、空闲且没有未保存蒙版／配色或其他弹窗时才运行；锁屏、切到后台、系统清理应用后不保证自动同步。电脑端改动会在手机下一轮同步时收到。

## 同时修改与中断

- 已有原图和素材按不可变版本保留，不因同步删除。新增蒙版和模型会合并；两端素材编号保持一致。
- 两端同时改同一份描述或调色方案时，原作品采用电脑侧该项内容，并在两端保留手机侧完整的“同步冲突副本”。可以分别打开继续编辑。重复同步不会重复创建相同冲突副本。
- 文件按 SHA256 校验并复用已有内容；无修改时不重复传输文件。作品全部素材接收和校验完成后才更新作品信息。取消或断网不会让未接收完整的作品覆盖本机内容；重新连接后重试，已校验的文件可复用。本版没有单个文件的字节级断点续传。
- 传输期间又发生修改，会提示重试并保留已有内容，避免静默覆盖。

同步上限为单文件 **64 MiB**、单作品 **512 MiB**；手机图片最多 1600 万像素。临时接收缓存限制 1 GiB，超过 7 天的缓存会在后续接收时清理。手机可在系统设置清理应用“缓存”；不要清除应用“数据”或卸载，否则本机作品和配对会被删除。

ComfyUI 地址、认证、授权证书和应用设置各端独立配置，不会通过作品同步复制。作品中的生成记录可能包含原服务地址与工作流，请只与自己的可信设备配对。

## 外网穿透

同步服务与 ComfyUI 是两个独立服务。为电脑同步服务新建 **TCP 隧道**，本地地址 `127.0.0.1`，本地端口 `8790`（或应用内设置的端口）。

**SakuraFrp 必须关闭该同步隧道的“自动 HTTPS”**，让 TCP 隧道原样透传应用自身的 TLS。该选项会终止远端 TLS 并向本地发送明文，而本应用的本地监听要求 HTTPS，二者不能叠加使用。依据：[SakuraFrp 自动 HTTPS 文档](https://doc.natfrp.com/frpc/auto-https.html)。这仅针对新建的同步隧道，不需要改动已有 ComfyUI 隧道。

配置隧道后，先关闭电脑同步服务，填写完整外网地址（例如 `https://your-host.example:12345`），再开启。应用会把该主机名加入证书；手机用此地址检查并核对指纹、授权、配对。HTTPS 反向代理也可使用路径前缀，但需把 `/qsync/v1` 路由原样转发到本机 HTTPS 服务，并正确验证其证书。

## 验证范围

本次使用隔离的 Windows 作品库和 Android 16 模拟器验证，未操作个人作品。验证包括跨端手动画笔、模型上色、配色与版本往返、冲突副本、无变化零文件传输，以及升级后的作品保留。自动化记录见 [同步验证](sync-validation/report.json)。用户尚未配置真实外网同步隧道，因此不将模拟穿透验证视为真实公网或实体手机验收。
