# 贴图与黏土调色

0.6.0 新增 Pixal3D 原生 AI PBR 贴图与保留材质换色，使用方法见 [PIXAL3D.md](PIXAL3D.md)。以下设计图投影流程与 0.4.0 验证记录保留，适用于混元与旧几何模型。

## 使用带颜色的模型

1. 先生成几何模型，并准备对应角色的透明抠图。可使用“手动修正”保存后的版本。
2. 进入“3D 工作台”，在下方“贴图上色与黏土调色”中选择检查过的抠图作为参考。
3. 默认保留设计图中的颜色。需要换色时，修改目标色块；可以把色块名称改为头发、服装、配饰等用途。相近颜色会一起变化，名称不会自动分割模型部件。
4. 点击“按设计图上色”。应用会保存配色、创建新的彩色 GLB 版本，原几何模型和已有彩色版本均保留。
5. 查看正面、侧面和背面。导入模型朝向不同，可调整“模型朝向”；细节对不齐时，可在“贴图对齐微调”调整缩放、位置和背面头部范围，再另存一个版本。
6. 使用“导出 GLB”导出带贴图模型。PNG 图片、UV 和颜色材质完整内嵌在一个 GLB 中，不需要复制外部贴图目录。STL 仍只有几何体。

在 Blender 中通过“文件 → 导入 → glTF 2.0”打开 GLB，切换为“材质预览”或“渲染”查看颜色。Blender 的实体视图默认不会显示颜色贴图。GLB 使用米；80mm 的导出高度对应 0.08m。

## 本版上色方式与边界

0.4.0 使用本地设计图投影和侧背颜色延展，不依赖 ComfyUI 贴图节点，不调用云服务。几何生成仍使用现有 ComfyUI 流程。本机当前没有安装独立的 Hunyuan3D-Paint 节点和模型，因此本版没有启用 AI 多视角纹理生成。

正面纹理来自透明参考图，删除区域只使用邻近前景颜色扩展，避免把抠掉的背景重新带进贴图。背面头部从上部轮廓取发色，身体颜色从参考图延展；面部不重复到背面。单图不能确定背面设计，服装图案可能重复、拉伸或接缝，遮挡部位及复杂姿势需要在 Blender 继续修绘。模型和参考图必须是同一角色、相近姿势；当前没有自动图像与网格配准。

输出是带颜色贴图的哑光材质，贴图为 2048×1024，使用 sRGB 颜色。没有生成独立法线、金属度或粗糙度贴图，也没有增加自动分件、骨骼或网格修复。模型上的“素色泥模”仅改变预览，GLB 导出仍保留实际贴图。

需要更完整的 AI 多视角纹理时，可在后续单独接入 [Hunyuan3D-Paint 官方流程](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1)，不能把当前投影结果视为该流程的输出。

## 黏土调色指引

- 从不透明前景提取最多 7 个主色。透明背景不参与取色，画面占比不代表黏土重量或体积。
- 点击人物预览可补取小配饰颜色，最多保留 12 色；取错的颜色可移除。可编辑颜色用途和目标色。
- 提供白、黑、红、黄、蓝、棕六种基础色；名称和色值可按手边材料修改。
- 每个目标色提供最多 3 种基础黏土的起始配方，以 20 个重量份计，允许小数份。可调整每色试配量，默认 5g，并查看各原料的克数和近似混色预览。
- 点击“保存配色”保存用途、目标色和基础材料，下次打开作品可继续使用。按设计图上色时也会保存当前配色。
- “导出调色指引”生成可保存或打印的 PNG，包含目标色、基础色、重量份、试配克数和操作步骤。

配方使用屏幕 RGB 的近似吸收混色模型，不是测量过的实体黏土配方。真实颜料浓度、品牌、含水量、揉合与干燥都会影响结果。应先称取主色，将深色分次少量加入，充分揉匀，保留湿样与干样比较；记录实际补色重量后再扩大用量。微量配料可先做色母或扩大试配量；显示克数经过四舍五入，以重量份为准。难以接近的颜色会提示补充相近成品色。
