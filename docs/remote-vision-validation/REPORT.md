## 实测中发现并修复的问题

0.9.0 把模型预填选区作为“未修改的基线”。画笔修改后撤销回建议框时，选区仍非空，但编辑器认为没有修改，“开始局部重绘”变灰。0.9.1 改为以空白蒙版为基线，并把预填选区记作首个可撤销步骤。撤销画笔后建议框仍可提交；继续撤销为空白时禁止提交；重做恢复后可继续。手动抠图仍以原蒙版为基线。

该问题在旧版 Windows 和 Android 均真实复现。修复后的安装包又逐步验证了初始框、涂选、撤销笔画、撤销初始框、重做初始框、重做笔画及开始重绘。新增两项回归测试，完整 Node 测试 72 项、Python 适配器测试 3 项、生产构建及 Android lintRelease 通过。最终 Windows 免安装包还完成了示例、手修蒙版、贴图与黏土配色烟测。Android 沿用原发布签名，可覆盖升级。

## 保留的限制与失败证据

第一轮 Windows 检测发生在 Ollama 服务重启时，得到连接拒绝并正确显示失败；服务恢复后重试成功，没有生成通过报告；未生成报告不代表一致性已通过。没有修改 ComfyUI 核心或重新安装节点。

模型把侧面口袋的透视线条也标成结构差异，区域框较宽，包含部分手臂。因此测试中人工选择把这处当作可选的口袋细节调整，并擦去部分手臂选区；这不意味着模型判断一定正确，也不能据此宣称检测准确率。后续检查仍返回待核对建议，没有自动标为“已解决”。

这是 Android 模拟器经过真实外网地址的网络与应用流程验证，不能替代实体手机、移动数据网络或厂商 WebView 验收。本次没有重新验证 3D 网格质量，也没有把“重绘完成”当作“所有视图已一致”。原有作品和历史验证文件保留，使用新建测试作品。
